# v0.1.1 Beta validation

## Change

Career Mode assists were already decoded and stored, but the history publisher required a manually certified Career, club and competition. The update publishes the stored count when the supported record layout and full save integrity can be verified. Existing registries can use the same observations without a migration. Competition classification and clean-sheet verification retain their existing rules.

## Automated checks

- Synthetic CRC-valid DATA exercise zero, one and multiple assists, league and cup rows, widened IDs, successive saves and separate seasons.
- Ambiguous club attribution and insufficient record evidence leave assists unknown. Historical inputs and native hooks are unchanged.
- Portable smoke tests cover setup, screen generation, relocation, incompatible executable handling and interrupted recovery with disposable profiles.
- The Windows executable and launcher report v0.1.1 Beta. Both ZIPs contain the versioned release files and exclude local registries, saves and private test files.

No live FIFA session was part of this validation. The supported executable and native BIN, save checksums, 2015/16 historical cutoff and competition scope are unchanged.
